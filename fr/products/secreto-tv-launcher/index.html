Secreto TV Launcher

Un écran d’accueil personnalisable pour Android TV et Google TV, conçu pour la télécommande.

Versions officiellesConfidentialité

Fonctionnalités

Vos applications

Organisez les favoris, recherchez les applications installées et masquez celles que vous ne souhaitez pas afficher.

Navigation TV

Utilisez les touches directionnelles et personnalisez le style Ocean Blue et les arrière-plans.

Informations facultatives

La météo et les horaires de prière sont configurables ; la disponibilité météo dépend des conditions du fournisseur.

Mises à jour et vie privée

Vérification des versions GitHub, préférences locales et redirection Accueil facultative via l’accessibilité.

Version et compatibilité

La prochaine version publique est en préparation. La version candidate testée nécessite Android 8.0 (API 26) ou une version ultérieure. Le fonctionnement dépend de l’appareil ; elle ne remplace pas systématiquement l’accueil système.

Consultez GitHub Releases pour les APK publiés. La prochaine version n’est pas encore annoncée comme disponible.
