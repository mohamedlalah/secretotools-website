Compatibility & connection

Phone or tablet: Android 8.0 (API 26) or newer.

Install the controller on Android 8.0 (API 26) or newer. The TV must support ADB debugging. Wireless pairing generally requires Android 11 or newer; available settings and features vary by manufacturer and firmware. Connect both devices to a trusted local network, enable debugging on the TV and approve the correct pairing code or authorization prompt.

Testing: the developer reports the signed release working on Samsung Galaxy A15. YOU-BOX discovery, connection and remote control were tested, with the individual build identity unrecorded. File, app, launcher and tweak testing took place during development; these are not all claimed as signed-release tests.

A closer look

Real application captures. Network identifiers and notification status areas are redacted in the supplied Galaxy A15 screenshots. Welcome and About are existing project captures; no final-build provenance is asserted for those two images.

Powerful tools. Use with care.

  • Use only devices you own or are authorized to administer. Revoke ADB authorization when finished.
  • Back up important data. Removing packages can delete data or break TV features; undo is not guaranteed for every operation.
  • Keep the original launcher and a recovery path. Record original DNS and system settings before changes.

Install on your Android phone or tablet

  1. Download the official signed APK using the Download APK link.
  2. Open the downloaded APK on your Android phone or tablet. The TV is the managed device; the controller is installed on your phone or tablet.
  3. If Android asks to allow installation from your browser or file manager, check the source and allow it only if you trust this download.
  4. Complete Android’s installation prompts. The website cannot bypass these security checks.
  5. Open Secreto TV Manager and follow the TV debugging, authorization and ADB pairing/connection instructions.

Use a trusted network. Disable wireless debugging and revoke ADB authorization when no longer needed.
