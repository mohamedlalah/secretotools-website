The idea

Make sending files to a television feel simple.

TV devices are excellent for playback, but moving files to them can be awkward. Secreto Hub turns the TV into a secure local receiver while the sender uses a straightforward browser page.

Browser on the sender

Use the device already in your hand without installing another mobile or desktop application.

Receiver on the TV

The TV displays the local connection address and receives selected files.

Same network

Transfers are designed to stay between devices connected to the same local network.

How it works

From browser to TV in four steps.

01

Start receiving

Open Secreto Hub on the TV and start the local receiving session.

02

Scan and pair

Use the QR code or local address shown on the television, then establish the session-specific pairing.

03

Choose files

Select or drag one or more files in the browser. Files are encrypted before transmission.

04

Receive on TV

Secreto Hub authenticates the transfer, decrypts completed data locally, saves files, and updates History.

Security & reliability

Secure transfer built into the workflow.

Secure Encrypted Transfer

Files are encrypted in the sender browser before transmission and decrypted locally by Secreto Hub on the television. No SecretoTools cloud account or external file-storage service is required.

Session-specific pairing

Each receiving session uses new pairing information to establish an authenticated transfer session.

Multi-file with retry

If one file fails, the remaining files can continue. Failed files and failure reasons are shown, and only failed files can be retried.

Requirements

What you need.

  • Android TV or Google TV receiver
  • Phone, tablet or computer with a modern browser
  • Both devices connected to the same local network
  • Enough free storage space on the TV device

Frequently asked questions
What is Secreto Hub?

An Android TV file receiver that lets another device upload files through a local browser page.

Does the sender need an app?

No. A modern browser on the sender is enough.

Are files uploaded to a SecretoTools server?

The product is designed for local-network transfers without an external SecretoTools file server.

Does it work outside the home network?

The intended workflow requires both devices to be connected to the same local network.

Is Secreto Hub already released on Google Play?

Version 1.0 is release-ready. Official Google Play availability is communicated separately when confirmed.

Are files encrypted during transfer?

Yes. Files are encrypted in the sender browser before transmission and decrypted locally by Secreto Hub on the television.

Can I send multiple files at once?

Yes. If one file fails, the remaining files can continue, and failed files can be retried separately.

Are received files opened automatically?

No. Received files are not opened or executed automatically.
