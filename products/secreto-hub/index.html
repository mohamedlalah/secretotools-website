The idea

Make sending files to a television feel simple.

TV devices are excellent for playback, but moving files to them can be awkward. Secreto Hub turns the TV into a temporary local receiver and gives the sender a straightforward browser page.

Browser on the sender

Use the device already in your hand without installing another mobile or desktop application.

Receiver on the TV

The TV displays the local connection address and receives selected files.

Same network

Transfers are designed to stay between devices connected to the same local network.

How it works

From browser to TV in four steps.

01

Start receiving

Open Secreto Hub on the TV and start the local receiving session.

02

Scan or type

Use the QR code or local address shown on the television.

03

Choose files

Select or drag files in the browser page on the phone or computer.

04

Receive on TV

Follow transfer progress and open the completed file or destination folder.

Core capabilities

A focused transfer experience.

QR connection

Open the sender page quickly without manually entering a long local address.

Multiple files

Select more than one file and follow transfer progress from the television.

Conflict handling

Incoming files can be renamed safely when a file with the same name already exists.

Clear progress

See current file status and completion information in a TV-friendly layout.

Flexible sender

Use a phone, tablet, Mac, Windows PC or another device with a modern browser.

Local operation

The receiving workflow is designed around the home or office local network.

Requirements

What you need.

  • Android TV or Google TV receiver
  • Phone, tablet or computer with a modern browser
  • Both devices connected to the same local network
  • Enough free storage space on the TV device

Frequently asked questions
What is Secreto Hub?

An Android TV file receiver that lets another device upload files through a local browser page.

Does the sender need an app?

No. A modern browser on the sender is enough.

Are files uploaded to a SecretoTools server?

The product is designed for local-network transfers without an external SecretoTools file server.

Does it work outside the home network?

The intended workflow requires both devices to be connected to the same local network.

Is Secreto Hub already released on Google Play?

Not yet. It is currently under active development and testing.
